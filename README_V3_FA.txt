ایران برد V3 — نسخه کامل تست Railway

تغییرات اصلی:
- طراحی مدرن و مینیمال با گرافیک/انیمیشن سبک PCB و خط تولید
- بخش فروشگاه قطعات الکترونیکی «به‌زودی»
- ثبت سفارش بدون حساب کاربری
- دریافت فایل‌های Altium و تصاویر/PDF
- کد پیگیری
- پیام مدیر برای «نیازمند تکمیل»
- پاسخ مشتری و فایل تکمیلی
- قیمت‌گذاری از پنل مدیر
- Agent آزمایشی مدیر بدون API پولی

روش جایگزینی:
1) ZIP را Extract کنید.
2) در GitHub Repository iran-board روی branch main بروید.
3) همه فایل‌ها و پوشه‌های داخل این پوشه را Upload کنید (نه خود پوشه IranBoard_V3).
4) Commit changes را بزنید.
5) Railway باید Deploy جدید را خودکار انجام دهد.
6) پس از Successful شدن، صفحه اصلی را باز کنید.
پنل مدیر: /admin.html
ثبت سفارش: /order.html
پیگیری: /track.html

نکته مهم: این نسخه برای تست است. برای استفاده واقعی باید ورود امن مدیر، دیتابیس پایدار و ذخیره فایل روی Object Storage اضافه شود.
