ایران برد - نسخه Full Demo

امکانات:
- صفحه اصلی Responsive
- ثبت سفارش بدون Sign in / ساخت حساب
- دریافت نام، موبایل و شرکت
- آپلود فایل PCB و تصاویر فالت
- تولید کد پیگیری یکتا
- پیگیری سفارش بدون ورود
- پنل مدیریت سفارش‌ها
- تغییر وضعیت و قیمت‌گذاری
- دستیار محلی نمونه برای مرتب‌سازی/تحلیل اولیه

اجرا روی کامپیوتر:
1. Node.js نسخه 18 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کنید: npm install
3. سپس: npm start
4. سایت: http://localhost:3000
5. پنل مدیریت: http://localhost:3000/admin.html

مهم برای Production:
این نسخه برای تست واقعی workflow ساخته شده، ولی قبل از انتشار عمومی باید:
- ورود امن مدیر و سطح دسترسی اضافه شود.
- دیتابیس production (PostgreSQL و مشابه) جای فایل JSON را بگیرد.
- ذخیره فایل‌ها به Object Storage منتقل شود.
- محدودیت نوع فایل، آنتی‌ویروس/اسکن آپلود و backup اضافه شود.
- HTTPS و تنظیمات امنیتی فعال شود.
- سرویس SMS بعداً از طریق API متصل شود.
- PDF پیش‌فاکتور رسمی و اطلاعات حقوقی شرکت اضافه شود.
- Agent واقعی به مدل AI متصل شود.

عبارت «قدیمی‌ترین کارخانه تولید برد مدار چاپی در ایران» طبق درخواست در سایت قرار گرفته؛ قبل از انتشار عمومی مستندات این ادعا بررسی شود.
