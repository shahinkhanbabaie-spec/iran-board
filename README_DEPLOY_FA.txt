ایران برد — نسخه کامل قابل استقرار روی سرور Node.js

امکانات فعال:
- سایت فارسی RTL و Responsive
- ثبت سفارش بدون ساخت حساب
- نام، موبایل و شرکت
- دریافت فایل‌های Altium Designer و ZIP/RAR پروژه
- دریافت چند تصویر پروژه/فالت
- تولید کد پیگیری
- پیگیری سفارش
- پنل مدیر
- تغییر وضعیت و قیمت سفارش

اجرای محلی:
1. Node.js 18 یا جدیدتر نصب باشد.
2. در پوشه پروژه:
   npm install
   npm start
3. مرورگر: http://localhost:3000

برای استقرار آزمایشی:
Build Command: npm install
Start Command: npm start
Port: از متغیر PORT سرویس به‌صورت خودکار خوانده می‌شود.

مهم برای استفاده واقعی:
این نسخه برای Demo کامل است. فایل‌ها و سفارش‌ها روی دیسک همان سرور ذخیره می‌شوند.
روی سرویس‌های آزمایشی با دیسک موقت ممکن است با Restart پاک شوند.
قبل از Production باید:
- دیتابیس پایدار (PostgreSQL)
- Object Storage برای فایل‌های Altium و تصاویر
- Login امن مدیر
- HTTPS و محدودیت/اعتبارسنجی آپلود
- PDF پیش‌فاکتور
- SMS API
- Agent واقعی مدیر
